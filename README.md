# nlp-main

Repositório do Trabalho de Conclusão de Curso **"Avaliação Automática de Respostas Curtas em Português Brasileiro: uma análise comparativa de representações textuais e modelos de regressão"** (Engenharia da Computação — UFRPE/UABJ, 2026).

**O código final, os resultados e o notebook com as tabelas do TCC estão na pasta [`tcc/`](tcc/).** Comece pelo [README da pasta](tcc/README.md).

A pasta `nlp-main/` contém a biblioteca AiBox NLP (licença MIT), usada para a extração das características do Coh-Metrix, e, em `nlp-main/tools/`, as versões exploratórias dos scripts desenvolvidas ao longo da pesquisa.
